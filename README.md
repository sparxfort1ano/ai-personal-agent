# Личный помощник-органайзер

## Назначение агента

ИИ-агент предназначен для управления личным расписанием: отслеживания дедлайнов по учебе в МАИ, напоминаний о днях рождения, мониторинга дат отборов на стажировки, планирования ежедневных задач по изучению чего-либо и т.д.

**Выбранный язык программирования:** `Go`

## Планируемые возможности

* Добавление и категоризация событий (учеба, стажировки, личное, спорт).
* Вывод расписания и планов на текущий день с учетом приоритетов.
* Система напоминаний о приближающихся дедлайнах и важных датах.

## Примеры использования

1. **Запрос пользователя:** "Добавь дедлайн по лабе по ИТ на 24 ноября и поставь напоминание на 1 ноября, что начнется отбор на стажировку в VK. Что у меня сегодня по плану?"
   **Ожидаемый результат:** `Дедлайн по ИТ на 24 ноября сохранен. Напоминание об отборе в YADRO установлено на 1 ноября. Сегодня по плану: разобрать фикстуры, шаблонизацию и хуки pytest и сходить на тренировку по хоккею.`

2. **Запрос пользователя:** "У кого из близких скоро день рождения и какие дедлайны горят на этой неделе?"
   **Ожидаемый результат:** `На этой неделе, в четверг, день рождения у Севы. Горящих дедлайнов по учебе до конца недели нет.`

## Технологический стек (ЛР 2)
- **Язык:** Go 1.25+
- **IDE:** Visual Studio Code
- **Хранение данных:** В оперативной памяти.
- **Линтер:** `golangci-lint`, используется встроенный в VS Code через конфигурацию `settings.json`.
- **Форматтер:** Встроенный `go fmt`.
- **Отладчик:** Delve (`dlv`), используется встроенный в VS Code через конфигурацию `launch.json`.

## Подготовка и запуск
1. Установите Go с официального сайта.
2. Склонируйте репозиторий.
3. Зависимостей в проекте пока нет, но в будущем для их установки потребуется выполнить `go mod download`.
4. Запустите приложение: `go run main.go`.
5. Для завершения работы введите команду `exit`.

## Проверка качества кода
- Форматирование кода: `go fmt ./...`
- Проверка линтером: `golangci-lint run`
